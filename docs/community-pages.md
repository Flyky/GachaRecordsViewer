# R15 米游社账号、Token 与刷新页面

日期：2026-10-27。入口 `/accounts`，授权获取手册 `/help/miyoushe`；主导航与登录重定向已接入。普通页面不增加管理员链接，管理页面仍只有创建用户和重置密码。

## 添加与管理账号

1. 从主导航进入“米游社账号”。可以添加多个本人米游社账号，与本地登录账号相互独立。
2. 首选“扫码添加账号 → 生成二维码”，使用官方米游社 App 扫描并确认。进入页面或打开扫码面板不会自动创建二维码。
3. 页面区分等待扫描、等待手机确认、正在验证保存、成功、过期、取消、官方验证和失败。扫码结果不确定时使用“检查扫码状态”，不要连续生成。
4. 已保存账号使用详情中的“重新扫码授权”，要求同一米游社身份；也可通过“更新凭证”替换整组凭证。验证失败不会替换旧值。
5. 手动导入支持 Cookie／JSON 文本。SToken 需对应的账号 ID 和 mid；只有 LToken 可校验身份，但没有角色列表与刷新能力；Cookie Token 可读取角色，仍不能替代 SToken。
6. 保存后更新账号与游戏档案，选择绑定 UID，与侧边栏当前档案同步。角色列表读取成功但没有原神角色，与未取得读取角色能力分别提示，不允许手工伪造归属。

账号卡片展示身份、角色、祈愿授权与最近校验状态。“已有 SToken，刷新时验证”不等于所有 UID／所有池已验证；“仅验证当前 UID 的临时授权”只校验所选 UID，不读历史，缺少 SToken 时不会显示成功可用。

“解除绑定”先确认目标身份、删除凭证／取消相关任务／保留历史的影响，再执行。网络错误无法确认结果时，先更新账号列表。解绑不等于撤销米游社的上游会话。

## Token 查看和复制

R17 新增“复制凭证”：在选中账号的本人 Token 区域一次复制 accountId、mid 和已保存 Token 的 JSON，可直接粘贴到“手动导入凭证”。仅主动点击时读取，浏览器拒绝自动复制时提供可手工选择的只读 JSON，沿用 60 秒／失焦／离开隐藏规则；不导出设备、主密钥或 AuthKey。详见 [R17 更新](r17-updates.md)。

- 默认列表与 DOM 只有存在状态、能力和遮挡值，不调用 reveal，也不带明文 Token 或 mid。
- 本人点击对应“查看”才请求该项明文；同时可看到对应身份 ID 和 mid。点击“复制”只复制 Token 值，不自动把它展示在页面。
- 明文只保留于组件内存：首次查看后最多 60 秒自动全部隐藏；窗口失焦、标签隐藏、离开页面、切换米游社账号或凭证操作也会清理。迟到的查看结果不能恢复已经隐藏或离开的页面。
- 不写入 localStorage／sessionStorage，不在错误提示或日志中回显。手动输入提交后清空，离开页面也清空。
- 复制依赖浏览器 Clipboard API，通常要求 HTTPS 或 localhost；失败时提示主动查看并手动复制。隐藏页面不会清空用户的系统剪贴板。
- 使用现有本地登录会话与 CSRF，不额外要求输入本地密码。手册已从旧草案修正为当前真实行为。

二维码通过本地 `qrcode` 编码，动态加载编码库；不把二维码 URL 发送给第三方生成服务。载荷不写入浏览器存储，结束或过期后移除图片。离开页面以原 CSRF 尝试取消未完成会话；取消网络失败或服务器正在原子保存时，不能承诺本地离开等于上游授权已撤销。票据仍受服务器有效期约束。

## 刷新与进度

选择 UID 后显示该档案的刷新区域，默认五个允许卡池与增量刷新，可选完整重扫当前窗口。没有已校验 SToken 时不能创建或重试刷新任务，历史任务仍可读取。渠道服额外显示尚未实测提示。

任务在后台运行，可以离开页面。当前 UID 已有活动任务时阻止重复创建，可直接查看运行中任务。切换 UID 清空本地任务视图与刷新选项，并重新读取该 UID 的任务；不会把上一 UID 的迟到响应写入新视图。

每 2.5 秒更新活动任务，扫码按服务器间隔至少 2 秒请求；均在前次请求完成后安排下一次，避免重叠。隐藏标签页暂停轮询，恢复可见后更新状态。网络错误暂停并提供手动更新，明确说明服务端任务可能仍在执行，不自动重提创建／重试请求。

进度显示“完成卡池数”，不假设上游已知总记录数；逐池显示成功页数、读取／新增／重复／补全、重试、状态和失败处理提示。部分完成可重试未完成池，服务中断可重试；取消保留已经写入的历史。终态任务的残留 queued／running 池明确显示其任务终态，避免误报仍在执行。

任务完成、部分完成或取消后更新档案数量和数据版本；“查看记录”和“导出 UIGF”接入原页面。较早历史可由 UIGF 合并补齐，在线窗口刷新不会删除本地历史。API 与后台限制见 [R14 刷新接口](sync-api.md)。
