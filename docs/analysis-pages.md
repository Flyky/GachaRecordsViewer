# R11：统计分析页面

日期：2026-10-27（Asia/Shanghai）。登录后通过导航「统计分析」或 `/analysis` 访问。未登录时先到登录页，登录成功返回分析页；统计仅作用于当前用户、当前 UID 的完整已保存记录。

## 物品分组

默认显示角色、数量从多到少。角色为五星／四星两栏，武器为五星／四星／三星三栏，支持角色／武器切换及数量正倒序。每栏显示获得总量，条目显示名称和数量，名称沿用星级颜色；名称缺失时显示物品 ID。

相同物品 ID 跨语言合并。能确定类型和星级的记录进入对应栏目，不能确定的记录单独列在「全档案暂未归类」中，可展开查看名称、ID、数量与原因。提示的范围是完整档案，包含当前物品类型之外的不明记录。详细计数口径见 [R10 分析 API](analysis-api.md)。

## 年月折线

保留总抽数、五星数、常驻池、角色活动池、武器活动池五条系列，按游戏时区归属月份，覆盖范围内缺月补 0。总抽数包含新手和集录；各系列有重叠，不能将五个合计相加当作总抽数。星级无法确定时明确提示五星数仅为已知部分。

- 点击图例复选框显示／隐藏系列，颜色固定。可用键盘操作复选框。
- 拖动底部滑块，或在图内使用滚轮／触屏缩放时间范围；悬停折线查看月份数据。
- 「重置图表」恢复全部系列和完整范围。
- 「查看月度明细」提供包含零月份的完整表格，便于逐项核对和辅助阅读。
- 空档案显示没有月度记录，不绘制误导性的趋势线。

图表按统计路由加载，使用 ECharts 6.1.0 的模块导入、折线与 SVG renderer。容器通过 ResizeObserver 调整图表，离开页面时释放实例和监听；普通窗口聚焦刷新、切换其他统计筛选且档案版本未变时，保留月度图的图例与缩放状态。依赖版本来自 [Apache 官方发布目录](https://releases.apache.org/catalog/echarts)，导入和生命周期依据 [按需导入说明](https://echarts.apache.org/handbook/en/basics/import/)与[容器尺寸说明](https://echarts.apache.org/handbook/en/concepts/chart-size/)。

## Daily 日历

默认年份由服务端按 Asia/Shanghai 当日年份选择，卡池默认不选即全部。年份选项覆盖当前年和历史记录年份。日期分组仍按所选游戏档案的时区，不跟随浏览器或服务端操作系统时区变化。

选择年份或卡池会更新 Daily，`301` 包含角色活动两个原始池；清除卡池选择恢复全部。该选择不改变物品或月度统计，也不读取查询页筛选。

日历按周排列，包含全年 365／366 个真实日期。没有抽卡的日期也有可交互色块，悬停、点击或键盘聚焦显示 `YYYY-MM-DD · N 抽`，包含闰日与 0 抽日。提示随窗口或内部滚动重新定位。颜色按所选年份与池的最大日抽数分档，全 0 时全部使用零值颜色，不进行无效除法。

键盘 Tab 进入日历后，上下键按日移动，左右键按周移动，Home／End 跳到年初／年末。每个日期有完整的可访问标签；触屏可点击色块查看。窄屏只在日历自身区域横向滚动，整页不横向溢出。

## 加载、切换和一致性

物品、月度、日历三份响应的档案 ID、数据版本和历史记录总量一致后才一起接纳。版本不一致时自动再取一轮，仍不一致则展示可重载提示；不混合不同版本的结果。失败时清空旧结果，可通过「刷新统计」重试。

同一 UID 更新期间标记加载并暂停统计控件；已显示结果仍标注原有年份和数据。切换 UID 会清空结果，并恢复角色、数量倒序、当前年和全部池。旧 UID 或旧账号的迟到响应会丢弃。没有档案时提供数据管理入口，空档案仍可查看完整全 0 日历。

## 本轮验证与边界

前端类型检查、零警告 lint、生产构建通过。图表路由采用独立分包，本轮约 571 kB（gzip 195 kB）；Vite 保留超过 500 kB 的体积提示，没有提高告警阈值或把图表加入其他页面的首屏代码。

使用合成记录和临时 SQLite，在本机 Edge 验证完整核心流程：

- 不同响应版本自动重取，三份统计对齐后显示。
- 角色／武器栏数、获得数量、数量排序及未知元数据提示。
- 五条折线、独立图例切换、实际滚轮缩放与重置、月度明细和零月份对账。
- 默认当前年／全部池、闰年 366 个日期、闰日和 0 抽 tooltip、角色活动合并及清除池筛选；Daily 筛选不改变月度数据。
- 键盘按日移动、图表 resize、390px 整页无横向溢出，检查桌面和手机截图。
- UID 切换重置、迟到响应隔离、空档案全 0 日历、离开／重新进入页面、A/B 账号隔离，无页面脚本异常。

浏览器检查发现并修复了图例状态读取以及空档案布局滚动后的 tooltip 定位问题。临时服务验证后关闭，真实用户 JSON 没有读取或导入；脚本、截图和合成运行数据不提交。后端与 Schema 未改动，没有重跑后端全量、PostgreSQL 或其他无关验证。

本轮只接入原有三组统计；米游社凭证与账号后端由 R12 开始。
