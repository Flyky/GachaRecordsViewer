# R17：在线物品字典、凭证复制与移动端统计

更新：2026-10-28（Asia/Shanghai）。本轮实现用户提出的三项更新，不新增配置文件或数据库迁移。

## 管理员刷新物品字典

直接输入 `/admin`（子路径部署如 `/gacha/admin`），登录后在“物品字典”卡片点击“刷新字典”。页面显示当前来源、版本指纹、条目数、获取时间和保存位置。

- 使用 [genshin-db 项目公开说明的 Web API](https://github.com/theBowja/genshin-db#web-api)，固定请求角色／武器各自的简中、英文数据，共 4 个请求；只读取 JSON，不执行远程脚本或动态安装 npm 包。
- 不向数据源发送账号、UID、抽卡记录或 Token；只有管理员主动点击才下载，正常启动及普通用户页面不自动联网更新。
- 整轮下载最多 45 秒，单个响应最多 8 MiB；校验 ID、名称、类型、星级、语言完整性、重复冲突，并拒绝丢失原有条目的截断结果。同一实例只允许一个刷新，期间旧字典继续可用。
- 完整校验后，以数据库事务替换原有 `item_metadata` 表中的原神字典，再切换本实例的活动字典。SQLite／PostgreSQL 复用同一仓储，无需迁移。网络／校验／保存失败时保留原字典。
- 重启优先读取数据库中的字典；没有缓存时使用随应用附带的固定快照，缓存损坏时回退并在管理员页提示。每个应用实例的字典独立，一个部署仍只运行一个应用进程。
- 在线版本标识为 `v5-内容哈希`，表示数据格式与内容指纹，不是游戏版本号；获取时间单独显示。

更新后，新发起的 UIGF 导入、记录查询、统计和米游社刷新立即采用新字典，不需要重启或重新构建。已经打开的普通页面可点击刷新或重新进入。字典不能提供新物品时仍保留未知状态；米游社返回空物品 ID 且无法反查的池，需更新字典后重试刷新。

历史记录保留物品 ID 和原始元数据，查询重新解析，不批量改写记录名称；数据概览的缺失提示也使用活动字典重新计算。原始记录已有名称时继续优先保留原名。导入预览附带字典版本，发生变化后需重新预览；分析响应包含 `dictionaryVersion`，前端避免混用不同字典版本的三组统计。

| 管理接口 | 请求 | 返回 |
| --- | --- | --- |
| `GET /api/admin/dictionary` | 管理员会话 | 来源、版本、数量、时间、保存位置和刷新状态 |
| `POST /api/admin/dictionary/refresh` | 管理员会话、Origin、CSRF、JSON `{}` | 成功后返回新状态 |

子路径部署时接口统一加前缀。无管理员会话返回 401，并发刷新返回 `409 DICTIONARY_BUSY`，失败返回 `502 DICTIONARY_REFRESH_FAILED`。普通页面仍不提供管理入口。

## 复制可导入的米游社凭证

在“米游社账号”选中本人账号，点击详情中“本人 Token”区域的“复制凭证”。复制的是可直接粘贴到“手动导入凭证”的 JSON，例如：

```json
{
  "accountId": "示例账号ID",
  "mid": "示例mid",
  "stoken": "示例SToken",
  "ltoken": "示例LToken",
  "cookieToken": "示例CookieToken"
}
```

上面只是字段示意，不是可用凭证。实际只包含已保存的字段，不输出设备上下文、加密密钥、密文或临时 AuthKey。仅有 LToken／Cookie Token 时也能导出对应输入格式。

新增 `POST /api/community/accounts/:id/export-credentials`，请求 `{}`，返回 `{ credentials }`。仅本人普通用户会话、同源和 CSRF 校验通过时可读取；其他用户返回 404，管理员会话不具备读取权限，响应禁止缓存。操作不访问米游社、不验证有效期，默认列表和页面加载不请求明文。

浏览器允许时直接写入剪贴板；HTTP 或浏览器权限导致复制失败时显示只读 JSON，供手动复制。手动显示的内容在 60 秒、失焦、页面隐藏、切换账号或离开时清除；不存浏览器本地存储。系统剪贴板由用户自行管理，应用不会自动清空。跨账号迟到响应不会写入新的账号视图。

## 统计卡片限高

“物品分组统计”的每个星级卡片最大高度为桌面 440px、窄屏 360px。标题和总次数保留可见，长列表在卡片内滚动；列表可用触摸、滚轮或键盘浏览，不隐藏记录。年月统计与 Daily 卡片保持原有布局。
