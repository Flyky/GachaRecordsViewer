# 账号页面（R05）

## 首次使用

1. 启动服务，在本机 `data/config.toml` 的 `[admin].password` 中读取管理员密码。
2. 在浏览器地址栏输入站点的 `/admin` 路径，例如开发环境 `http://127.0.0.1:5173/admin`。
3. 使用固定账号 `admin` 登录，填写普通账号名称并创建。页面显示初始密码 `12345678`。
4. 使用者打开 `/login`，输入自己的普通账号和初始密码。

普通页面没有管理员按钮或链接，没有自助注册入口。管理页提供创建账号和重置密码，账号列表用于选择重置对象；R17 按用户新需求增加“物品字典”刷新按钮，显示来源与获取时间，成功后立即生效，失败保留旧字典。详见 [R17 更新](r17-updates.md)。管理员与普通用户可以在同一浏览器分别保持会话，退出其中一个不会主动退出另一个。

## 登录、提醒与改密

初始密码登录后，在页面上方显示非强制提醒。点击“暂时忽略”可继续访问；同一次登录中切换页面不会反复出现。在 HTTPS 或本机 localhost 环境下，刷新页面也保持忽略状态；浏览器存储被禁用时仍支持页面内忽略。

提醒的持久状态使用 sessionStorage 中的会话单向摘要，不保存密码、Cookie 或 CSRF 令牌原文。新的登录生成新的会话，使用初始密码时会重新提醒。非安全 HTTP 且浏览器没有 Web Crypto 时，仅在当前页面生命周期内保留忽略状态。

在“个人设置”中填写当前密码、新密码和确认密码，提交后撤销全部旧登录，并返回登录页提示使用新密码重新登录。新密码为 8–128 个字符，两次输入必须一致；密码不去空格。当前密码错误或网络异常会在表单附近显示说明。

管理员重置密码前会弹出确认框，明确显示目标账号、重置值 `12345678` 和所有旧登录失效的影响。重置后重新登录会恢复初始密码提醒；已有抽卡记录保留。

## 页面状态与边界

- 未登录访问受保护页面时跳转登录；登录后恢复允许的目标页，外部 URL 不用作跳转目标。
- 会话失效后清除前端账号状态并要求重新登录；切换账号时，账号页面按用户 ID 重新建立，避免沿用前一个账号的表单状态。
- 登录用户返回页面焦点时刷新认证状态。网络失败不会伪装成成功，也不会在退出失败时显示已退出。
- 写请求带当前身份的 CSRF 令牌；会话和 CSRF 仅保存在浏览器 Cookie／运行内存中。管理员列表、密码表单不会通过公共页面提供。
- 正在提交时禁用相关操作，错误、成功和重置结果有明确提示；表单支持标签、密码自动填充、键盘提交与密码显隐。
- 当前游戏档案选择器处于“暂无游戏档案”状态；查询、分析和数据管理导航标为即将开放，不展示虚构 UID 或统计。真正的档案切换从 R08 接入。

## 本轮精简验证

仅执行前端类型检查、前端 lint、前端生产构建及一次隔离浏览器核心流程。流程包括：管理员创建 → 初始密码登录 → 关闭提醒并切页／刷新 → 修改密码 → 新密码登录 → 退出／再登录 → 管理员重置 → 旧会话失效 → 初始密码重新登录并恢复提醒。另检查普通页面无管理入口、390px 页面无横向溢出、无页面脚本异常。

浏览器使用独立临时 SQLite 和合成账号；测试数据、截图与脚本放在忽略目录中，不改动真实账号和 JSON。没有重跑 R04 全量后端测试或 PostgreSQL 集成。
