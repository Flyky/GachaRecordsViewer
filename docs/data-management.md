# R08：数据管理与多 UID 页面

日期：2026-10-27（Asia/Shanghai）。本轮接入 R07 后端，入口为登录后的「数据管理」或直接访问 `/data`。未登录时会先到登录页，成功后返回数据管理。

## 导入

1. 选择 UIGF v4.0、v4.1 或 v4.2 JSON 文件，页面自动请求预览。
2. 查看每个原神 UID 的游戏时区、语言、文件行数、时间范围、预计新增、重复和元数据补全数量。缺失或冲突元数据单独提示；其他游戏块明确列为跳过。
3. 默认选中可导入的 UID，可逐项取消。存在关键字段冲突、时区冲突或多个合并目标的档案不可选；可展开记录 ID 和冲突字段详情，其他可导入档案仍可选择。空档案也可以保存。
4. 点击「确认导入所选档案」，完成后显示新增总量及每个所选 UID 的实际结果，并更新当前账号档案列表。重复导入会显示新增 0 条。

预览会把文件发送到当前部署服务，只有确认选中的原神档案才会写入。文件和预览只保存在当前页面内存；离开页面、退出或切换本地账号后清空。旧工具内部 JSON 不支持导入，也不提供历史迁移。

单次文件上限 16 MiB，服务端还限制 JSON 请求体、最多 32 个原神档案和 100,000 条记录。读文件失败、JSON 损坏、未知版本、错误必填字段、无原神数据等均有页面提示；没有原神档案时不显示确认导入操作。

预览有效期为 15 分钟。文件或登录状态改变、预览过期、后台档案已变化时，需点击「重新预览当前文件」再确认；旧预览不能直接重试。重新预览保留仍合法的 UID 选择。网络中断或响应损坏时，页面明确提示服务端可能已经写入，先更新列表并重新预览，再决定是否重试。服务端按记录 ID 去重。

## 多 UID 和概览

侧栏「当前游戏档案」显示当前本地账号拥有的原神 UID；手机版选择器位于导航上方。选择会更新概览与导出目标。导入以预览中勾选的 UID 为准，独立于当前查看的 UID。

选择器只在当前账号的档案集合中接受选择。浏览器 `sessionStorage` 按本地用户 ID 记住档案 ID，同一标签页刷新或重新登录时可恢复；不保存 JSON、预览凭据或抽卡记录。旧档案已不存在时选择列表首个可用档案。切换本地账号会立即清空列表、当前档案和错误状态，旧账号的迟到响应会丢弃。

概览显示当前 UID、地区／离线档案标记、记录总量、游戏时区、最早／最近记录及元数据缺失数量。时间直接使用游戏时区中的记录时间。空账号显示导入入口；档案加载失败时提供重试。导入成功保持原有有效选择，没有选择时使用首个可用档案。

保存了记录不代表历史完整，离线导入不会自动确认第一抽。查询和统计功能按 R09–R11 继续实现。

## 导出

在数据管理页确认当前 UID，选择版本后点击「下载 UIGF 文件」。默认 v4.0，可选 v4.1/v4.2；导出该 UID 的全部已保存记录。文件名包含版本、UID 和时间戳，使用标准 JSON 下载。

v4.2 的记录 ID 最多 19 位；旧版本中的更长 ID 保持原值，遇到版本不兼容提示时可改选 v4.0/v4.1。数据未加载或没有档案时不可下载。下载接口仍校验当前用户权限。其他游戏内容、文件中的自定义授权字段均不进入导出。

后端协议、事务、去重、字段保留与版本限制详见 [R07 文档](uigf-import-export.md)。

## 验证记录

按精简验证策略执行前端类型检查、零警告 lint 和前端生产构建。使用合成账号及临时 SQLite，在本机 Edge 完成隔离浏览器流程，覆盖：

- 上传、默认选择和取消 UID、选定导入、重复导入新增 0、多 UID 切换、刷新和重新登录后的选择恢复。
- 下载默认 v4.0 文件并核对记录集合、长字符串 ID 与授权字段排除。
- 元数据缺失、旧格式拒绝、损坏 JSON、没有原神块、跳过其他游戏、空档案保存、关键冲突详情与禁选。
- 另一请求更新档案后旧预览被拒绝，重新预览后可确认。
- 同一浏览器标签页 A/B 账号独立保存相同 UID，A 退出后迟到的预览不会进入 B 页面，返回 A 后仍保留自己的数据与选择。
- 390px 页面无横向溢出，没有页面脚本异常；检查桌面与手机版截图。

内置浏览器工具本轮因本地运行环境错误无法启动，改用已安装的 Edge 执行上述流程。临时服务验证后关闭；脚本、截图及合成运行数据留在忽略目录，不进入提交。本轮没有读取或导入用户真实 JSON，没有重跑后端全量、PostgreSQL 或其他无关验证。
